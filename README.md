# dotfiles

My dotfiles and configs. Thanks [chezmoi](https://www.chezmoi.io/quick-start/#start-using-chezmoi-on-your-current-machine) for making it so simple.


## Requirements
* `chezmoi` (pacman)
* `chezmoi_modify_manager` (e.g. yay)

## Setup

* Install requirements
* Clone this repo to path `~/.local/share/chezmoi`
* Run:
```bash
chezmoi apply
```
